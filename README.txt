飞行汽车课程作业

文件结构：
- index.html：两次作业入口页
- 作业一/index.html：飞行汽车全方位调研与分析
- 作业二/index.html：飞行汽车全方位安全分析

本地查看：
解压后打开 index.html，即可进入两份作业。

发布到 GitHub Pages：
1. 在 GitHub 新建 Public 仓库。
2. 将解压后的全部文件上传到仓库根目录，保留“作业一”和“作业二”文件夹。
3. 打开仓库 Settings → Pages。
4. Source 选择 Deploy from a branch。
5. Branch 选择 main，目录选择 /(root)，保存。
6. 部署完成后，访问 https://你的用户名.github.io/仓库名/

两份作业统一使用小鹏汇天「陆地航母」飞行汽车作为研究对象。
