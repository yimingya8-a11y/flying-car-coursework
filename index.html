一、研究对象与调研目的

本次作业选择小鹏汇天「陆地航母」作为研究对象。它不是把普通汽车简单加装飞行装置，而是由一台可在道路上行驶的陆行体和一架可垂直起降的飞行体组成。陆行体负责运输、收纳和补能，飞行体负责短距离低空飞行，两者通过车载自动分离结合机构连接。

选择这款产品，主要是因为它已经完成实车公开展示和飞行演示，产品结构比较清楚，既涉及汽车工程，也涉及航空器设计、电推进、飞行控制和适航管理，适合从技术、应用和市场三个方面进行分析。

调研主要围绕产品定位、企业背景、系统组成、关键技术、技术可行性、使用场景、市场需求和同类产品展开，并结合公开资料分析其目前的优势和需要解决的问题。

二、企业与产品概况

1. 企业背景

小鹏汇天成立于2013年，是小鹏汽车生态体系中的飞行汽车企业，总部位于广东广州。企业主要开展飞行汽车及相关低空产品的研发，产品方向包括个人飞行、低空出行和飞行体验等。与传统航空制造企业相比，小鹏汇天同时具备汽车产业链和智能电动汽车领域的研发经验，这为其开发陆行体、动力系统和智能控制系统提供了基础。

2. 产品定位

「陆地航母」定位于个人和家庭使用的分体式飞行汽车。陆行体外观和功能接近大型智能汽车，能够在道路上行驶；飞行体可以从陆行体后舱中取出，展开机臂和旋翼后进行垂直起降。飞行结束后，飞行体可重新收纳到陆行体内，由陆行体承担地面转运和补能任务。

三、产品系统组成

「陆地航母」可以划分为陆行体、飞行体和两者之间的分离结合接口。每个部分承担不同任务，但在运输、补能和飞行准备过程中需要相互配合。

陆行体

  • 采用三轴六轮设计，支持6×6全轮驱动和后轮转向，兼顾承载能力和道路通过能力。
  • 后部设置飞行体收纳空间，能够在地面移动过程中携带飞行体。
  • 陆行体搭载增程式电驱动力平台，同时承担飞行体的移动补能任务。
  • 陆行体需要满足汽车的道路行驶、碰撞防护、制动、转向和车辆管理要求。

飞行体

  • 采用六轴六桨双涵道构型，机臂和旋翼可以折叠，便于收纳。
  • 采用双人座舱，公开资料介绍座舱具有270°全景视野。
  • 采用分布式电推进系统，电机和旋翼共同提供垂直起降所需的升力。
  • 飞行体配备飞控、导航、通信、供电和人机操纵等系统。

分离结合机构

该机构是产品最有特点的部分。飞行前，陆行体将飞行体移动到合适位置，机构完成定位和分离；飞行结束后，飞行体收拢机臂和旋翼，再与陆行体完成对接。自动分合可以减少传统航空器转运和存放的麻烦，但也增加了机械定位、锁止确认和电气连接等技术要求。

四、关键技术分析

关键技术基本原理在产品中的作用需要解决的问题
分布式电推进多个电机分别驱动旋翼，通过控制各旋翼转速调节总升力和姿态。提供垂直起降和悬停能力，便于实现多电机布局。电机、电调、桨叶和电源之间需要协调；单个部件故障会改变推力分布。
六轴六桨双涵道多个旋翼分布在机体周围，涵道结构对旋翼形成包围。提供飞行升力，并兼顾结构布置和旋翼防护设计。涵道气动效率、噪声、散热、结构重量和维修便利性需要平衡。
800V高压电平台提高系统电压，在相同功率下可降低电流，减少线束损耗。为飞行电池、电驱和相关设备供电，提高电能传输效率。高压绝缘、电弧防护、电磁兼容、热管理和维修安全要求较高。
自动分离结合通过定位、驱动和锁止机构完成飞行体与陆行体之间的自动对接。解决飞行器地面运输、收纳和补能问题。需要保证定位精度、锁止可靠性、接口耐久性和异常状态处理能力。
飞行控制与导航飞控系统采集姿态、位置和动力状态信息，计算控制量并分配到各电机。维持飞行姿态，完成起飞、悬停、航线飞行和降落。需要处理传感器误差、定位干扰、通信中断和软件异常。
复合材料结构采用碳纤维复合材料实现较高比强度和较低结构质量。减轻飞行体和旋翼结构重量，提高有效载荷利用率。需要控制层间分层、冲击损伤、疲劳和制造质量差异。

电推进系统的特点

与燃油发动机相比，电机具有响应快、结构相对简单、控制方便和维护环节较少等特点。分布式电推进把动力分配到多个电机上，有利于通过不同电机的转速变化控制飞行器姿态。但多个电机并不意味着绝对安全，电源、控制器、线路或软件出现共同原因故障时，仍可能影响多个推进单元。

高压平台的作用

飞行器在短时间内需要较大的功率。提高母线电压可以在相同功率下降低电流，从而减小线束损耗和部分导体重量。但高压系统对绝缘距离、连接器、接触器、维护工具和人员防护提出了更高要求。高压平台带来的效率收益，需要与安全防护和热管理一起考虑。

自动分合机构的意义

传统小型航空器通常需要拖车或专用设备运输，停放和转场也比较麻烦。陆地航母把飞行体放入陆行体后舱，能够把地面移动、收纳和补能结合起来。该机构的难点不只是“自动移动”，还包括对接误差补偿、锁止状态确认、结构承载、振动环境和多次循环后的可靠性。

五、技术可行性分析

1. 飞行原理可行

多旋翼电动垂直起降技术已经用于工业无人机和部分载人eVTOL产品。多个旋翼产生升力，飞控系统通过调节不同电机转速控制滚转、俯仰、偏航和高度。六轴六桨方案在原理上能够实现垂直起降和悬停，技术路线具有现实基础。

2. 关键部件具有产业基础

高功率电机、功率电子器件、锂电池、碳纤维复合材料、惯性传感器和卫星导航设备已经形成较成熟的供应链。汽车产业在电驱、电池管理和电子控制方面的积累，可以为飞行汽车提供部分技术基础。不过，航空器对重量、可靠性、环境适应性和故障后果的要求更严格，汽车部件不能未经验证直接用于航空器。

3. 工程集成难度较高

飞行体需要在有限重量内布置电池、电机、控制器、结构和乘员舱。电池重量会影响载荷和航程，旋翼尺寸会影响收纳空间，涵道结构会影响气动效率和噪声。陆行体又需要容纳飞行体，同时保留道路车辆的乘坐空间、底盘和碰撞防护。两套系统组合后，整车尺寸、质量和成本控制都比较困难。

4. 技术可行性判断

项目判断理由
多旋翼垂直起降可行性较高已有多旋翼航空器和载人eVTOL产品作为技术基础。
高压电推进可行性较高电驱和功率电子技术成熟，但航空级可靠性仍需验证。
自动分离结合工程难度较高需要解决精确定位、机械锁止和电气接口可靠性。
飞行控制与自动飞行可实现但要求高控制算法已有基础，复杂天气和异常情况下的安全能力更关键。
个人用户规模化使用仍需条件支持受适航、驾驶资格、空域、起降点、价格和维修网络影响。
总体来看，产品的核心技术路线具有可行性，但真正决定产品能否投入使用的，不只是能否完成飞行演示，还包括长期可靠性、适航审定、生产一致性和运行保障能力。

六、应用场景分析

低空观光与飞行体验

在风景区、海岛、湖泊和山地周边设置合规起降点，开展短途观光和体验飞行。该场景航线相对固定，便于集中管理，但需要控制噪声、天气和游客安全。

郊区与营地出行

用户先驾驶陆行体前往郊外，再在指定场地使用飞行体完成短途飞行。陆行体能够解决飞行器从存放地到起降点的转运问题。

岛屿与沿海短途交通

在岛屿、海湾和沿海地区，飞行器可以提供点对点交通补充。实际使用必须考虑海风、盐雾、备降点、救援和通信覆盖。

私人飞行与社交体验

面向有较高消费能力、具备飞行条件和培训能力的用户，提供私人飞行体验。早期更可能以体验和休闲为主，而不是日常通勤。

短期不适合的场景

  • 高密度城区的自由飞行：建筑物密集，空域协调、噪声和地面风险控制难度大。
  • 全天候通勤：低空飞行受风、雨、能见度和温度影响，不能简单替代地面交通。
  • 大规模公共交通：双座飞行体载客量有限，需要完善起降场、航线、调度和运营体系。

七、市场可行性分析

1. 市场环境

低空经济逐渐成为国内新兴产业方向，相关产业包括航空器制造、电池、电机、飞控、通信、起降场、维修保障和运营服务。国家信息中心在2024年发布的研究文章中提到，低空经济具有产业链长、应用场景多等特点，同时指出基础设施建设、关键技术、市场体系和管理制度仍需完善。由此可见，行业发展空间较大，但市场成熟度还不均衡。

2. 目标客户

客户类型购买 / 使用动机主要顾虑
高净值个人与家庭个性化出行、飞行体验、休闲娱乐。售价、维护费用、飞行资格、停放和使用限制。
旅游景区与度假区增加观光项目，提升游客体验和客单价。运营许可、天气影响、人员培训、事故责任和保险。
飞行营地与体验机构建设飞行体验服务，形成设备销售和服务收入。起降场建设、设备利用率、维护成本和客户安全。
企业客户品牌展示、技术体验、定制化飞行活动。采购成本、使用频率和合规要求。

3. 商业模式

产品可能采用整机销售与后续服务相结合的方式。整机销售包括陆行体和飞行体；后续收入可能来自维护保养、飞行培训、营地体验、软件服务、配件和电池相关服务。对企业来说，建立飞行营地和服务网络有助于提高产品使用频率，也能减少用户自行寻找起降点的困难。

4. 市场可行性判断

从需求侧看，飞行体验和高端休闲出行具有一定消费群体，产品的分体式设计也有较强辨识度；从供给侧看，汽车产业链和航空产业链可以提供部分制造基础。但个人飞行器的购买价格、运营成本和使用门槛都较高，早期市场规模不容易迅速扩大。短期内，景区体验、飞行营地和高端用户可能比普通家庭日常通勤更容易形成实际需求。

市场能否真正形成规模，关键不只在于消费者是否感兴趣，还取决于适航证书、驾驶与运行规则、起降点数量、保险、售后维修和实际使用成本能否逐步完善。

九、SWOT分析

优势 Strengths

  • 分体式设计具有明显差异化。
  • 陆行体解决飞行器地面转运和收纳问题。
  • 可利用汽车电驱、电池和智能制造方面的经验。
  • 六旋翼分布式电推进便于进行多电机控制。

劣势 Weaknesses

  • 整套产品结构复杂，研发和制造成本较高。
  • 双系统增加重量、空间和维护要求。
  • 飞行体载客量只有两人，应用范围有限。
  • 用户需要同时面对汽车和航空器两类使用要求。

机会 Opportunities

  • 低空经济政策和产业链逐渐发展。
  • 旅游观光、飞行体验和郊区休闲存在潜在需求。
  • 电池、电机、复合材料和控制技术不断进步。
  • 飞行营地和低空基础设施可能带来服务收入。

威胁 Threats

  • 适航审定周期和投入较大。
  • 同类eVTOL企业竞争激烈。
  • 空域管理、起降场和保险体系仍需完善。
  • 安全事故可能影响公众信任和市场接受度。

发展建议

  1. 先在飞行营地、景区和固定航线中积累使用经验，再逐步扩大使用范围。
  2. 把产品可靠性、维修便利性和售后保障放在宣传和销售之前。
  3. 与地方政府、起降场运营方和保险机构合作，完善地面服务网络。
  4. 根据用户反馈优化收纳、补能、噪声控制和座舱舒适性。

十、总结

通过对小鹏汇天「陆地航母」的调研，我认为这款产品最大的特点是把道路交通和低空飞行结合起来。陆行体负责地面移动、收纳和补能，飞行体负责垂直起降和短途飞行，自动分离结合机构则把两个部分连接起来。这种设计针对传统小型航空器运输和存放不方便的问题提出了新的解决思路。

从技术角度看，分布式电推进、高压电平台、飞行控制、碳纤维结构等技术都有现实基础，但整机集成仍然复杂，特别是电池能量密度、飞行续航、噪声、结构重量、分合机构可靠性和适航验证等问题。从应用角度看，景区观光、飞行营地和高端休闲体验更适合早期发展；从市场角度看，产品有差异化卖点，但价格、使用门槛、起降设施和运营规则会影响普通消费者的购买意愿。

总体而言，「陆地航母」具有一定的技术可行性和市场探索价值，但距离成为普通家庭日常交通工具还有较长的路要走。未来能否成功，取决于产品安全性、适航进度、使用成本和配套服务能否同步发展。
